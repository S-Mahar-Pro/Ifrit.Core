## 🚀 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation
```bash
git clone https://github.com/S-Mahar-Pro/Ifrit.Core.git
cd Ifrit.Core
npm install
```

### Environment Setup
```bash
cp .env.example .env.local
# Configure with your settings
```

### Development
```bash
npm run dev
# Open http://localhost:3000
```

### Build & Deploy to Netlify
```bash
npm run build
# Deploy to Netlify
netlify deploy --prod
```
